# DIPYatzy

### Lavet af Nicklas og Lucas.

Der er blevet hjulpet fra AI til at lave lidt af gui'en da vi blev enige om at dette ikke var fokus området. Der er selv blevet lavet diverse div's og input, samt billederne.
<p>
Det som AI har hjulpet med er alle farver og også hjulpet med at gøre det pænt. Som sagt besluttede vi css flair ikke var den primære del af opgaven.
